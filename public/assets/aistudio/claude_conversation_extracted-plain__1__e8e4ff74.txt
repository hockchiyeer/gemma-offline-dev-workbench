## What `setup:gemma` does (and does not) download
`npm run setup:gemma` (also run by `setup-and-start.bat`, and by **Runtime settings → Auto-setup Gemma** in the app) checks before it acts, in this order:
1. **Ollama present or running?** If yes, the installer is **not** downloaded. The installer is fetched only on Windows, and only when Ollama is neither found nor responding. It is the official `OllamaSetup.exe`, must carry a valid digital signature issued to Ollama (`CN=Ollama` / `O=Ollama`), and installs silently for the current user (no admin prompt). macOS/Linux get exact manual instructions instead (they need sudo/Homebrew).
2. **Service running?** If not, it is started. Ollama's folder is added to the Windows User `PATH` and existing shell profiles (`.bashrc`, `.bash_profile`, `.zshrc`, `.profile`) if missing.
3. **Model already installed?** If the exact tag is present it prints `<model> is already installed.` and downloads nothing. Only otherwise does it pull the model (the large download).
It first prints a status line (for example `Ollama installed (on PATH) · service running · models: gemma4:e4b`), which is your confirmation of what it found.
**Which model.** It targets one picked from your RAM: `gemma4:e2b` under 7 GB, otherwise `gemma4:e4b`. Larger models are never auto-selected. Choose explicitly with `npm run setup:gemma -- --model gemma4:26b`. Only Gemma-family tags are accepted.
**Two cases where a download can still happen**
- You only have a *different* model (say `gemma4:26b`), so the recommended `e4b` is missing and gets pulled as well. Run with `--model <the tag you have>`, or skip setup and just `npm start`: the app auto-selects the best installed Gemma. List what you have with `ollama list`.
- You installed it under another tag (bare `ollama pull gemma4` makes `gemma4:latest`). Tags are compared exactly, so `e4b` looks missing. Ollama stores model files by content, so re-pulling the same model should reuse them and finish quickly, but if a large progress bar appears, press Ctrl+C.
If a firewall blocks `ollama.com`, install Ollama manually and run `ollama pull gemma4:e4b`. Auto-setup is disabled when `HOST` exposes the server beyond loopback.

| **Debug** | Audit for bugs, race conditions and security flaws, and return a fixed version. | Yes |
| **Refactor** | Improve clarity, modularity and idiomatic style. | Yes |
| **Expand** | Implement stubs, TODOs and comment specs into working code. | Yes |
| **Unit Tests** | Write tests for normal and boundary cases. | Yes |
| Any other prompt with a snippet attached (paperclip) | Whatever you ask. | Yes, labelled **AI Variant** |
**How children are saved**
- Every complete fenced code block in the reply becomes one child (`v2 Refactor (1/2) · <parent title>`), nested under its parent in the list. A code block that never closes, because the reply hit the token limit or you pressed Stop, is ignored, so half-written code is never saved as a version.
- A child records the action, model, capture time and prompt in **Engineering Notes**, inherits the parent's tags plus an action tag, and shows **Parent** and **Derived** links so you can jump between versions. Chat replies link straight to the snippets they created.
- Deleting a snippet keeps its children: they move up to the deleted snippet's parent.
- Children are ordinary snippets: they are searchable, editable, covered by vault encryption and included in `.gvbackup` files.
## Slow or stuck answers
Gemma 4 normally *reasons* before it writes the answer. On a CPU-only machine that phase can take minutes for a simple question, so the chat shows what it is doing while you wait:
| Chat shows | Meaning |
| --- | --- |
| `Loading model into memory… Ns` | Nothing has come back yet: the model is loading or reading your prompt. The first request after idle is the slowest. |
| `Reasoning… Ns` | The model is thinking. Open **Show reasoning** to watch it; the answer follows. |
| `Generating… Ns` | The answer is streaming. |
**Make it faster**
1. **Runtime settings → Reasoning (Ollama) → Off.** Sends `think: false`, so the model answers directly. *Auto* (the default) lets the model decide and gives the best quality. This setting applies to Ollama only; OpenAI-compatible servers ignore it.
2. **Check where the model runs.** While it is loaded, `ollama ps` shows CPU or GPU in the `PROCESSOR` column.
3. **Use a smaller model**, for example `gemma4:e2b` (see [Choosing a model](#choosing-a-model)). `ollama run gemma4:e4b --verbose "hello"` prints the speed in tokens/s; a CPU-only rate below about 5 tokens/s will always feel slow.
**Token budget.** *Max Output Tokens* is the length of the answer. In *Auto*, the app asks Ollama for 4096 extra tokens so reasoning cannot use up the answer's budget, and it reserves that room from the *Context Window* when trimming long chats or attached snippets. With *Off*, no extra room is reserved.
**Stop and timeouts.** The red stop button keeps whatever has streamed so far. If nothing arrives for 5 minutes at the start, or the stream goes silent for 90 seconds mid-reply, the request is cancelled with an error instead of waiting forever.
**Messages you may see**
| Message | Fix |
| --- | --- |
| `…used its entire token budget on reasoning and produced no answer` | Raise *Max Output Tokens*, or set Reasoning to Off. |
| `…finished reasoning without producing a final answer` | Rephrase the prompt, or raise *Max Output Tokens*. |
| `…returned an empty answer with Reasoning turned off` | This Ollama build needs thinking on: set Reasoning back to Auto. |
| `The local model stopped responding (no data received)` | Check that Ollama is running and the model fits in RAM (`ollama ps`), then retry. |
**Page looks unchanged after an update.** The installed PWA caches the app. Hard-refresh with Ctrl+Shift+R. If the old behaviour persists, open DevTools → Application → Service Workers and click **Unregister**, then reload. Do **not** use "Clear site data": it also deletes your IndexedDB vault.

## Network & Security Notes
- **Loopback by default.** Locally, the server binds to `127.0.0.1` and rejects requests whose `Host` header is not a loopback name (DNS-rebinding defense). To use GemmaVault from a phone on your Wi-Fi, opt in explicitly: `HOST=0.0.0.0 npm start`. The app has no login, so only do this on a trusted network; enable the vault passphrase first.
- **Containers.** When `K_SERVICE` or `APP_URL` is set (managed container hosts) the server binds `0.0.0.0` by default and the Host-header and setup-endpoint guards relax accordingly; set `HOST=127.0.0.1` to force loopback. In this mode it also omits `X-Frame-Options: DENY` and the CSP `frame-ancestors` directive so preview iframes can embed the app; local runs enforce both. Don't leave `APP_URL` set if framing should stay blocked.
- **Installed PWA without the Node server.** The browser then talks to Ollama directly, which requires CORS. This is the one case where you start Ollama yourself: quit any running Ollama first, then run `OLLAMA_ORIGINS="http://localhost:3000" ollama serve`. (With `npm start` / `npm run dev` the built-in proxy handles CORS and this is not needed.)
- **Encryption is opt-in.** Until you set a passphrase in *Vault DB*, data is stored unencrypted in IndexedDB. A lost passphrase cannot be recovered — keep a `.gvbackup`.
- **Reasoning traces and snippet lineage are stored.** A reply's reasoning ("Show reasoning") and derived child snippets (`parentId`, `derivedAction`, `version`, and provenance notes) are saved with their session or snippet in IndexedDB, so they are covered by vault encryption and included in `.gvbackup` files. Setting Reasoning to Off stops new reasoning traces from being created.
- **Multiple tabs.** Locking one tab locks all; changing encryption or importing a backup reloads the others.

function createSecurityHeaders(production: boolean, managedContainer: boolean) {
return (_req: Request, res: Response, next: NextFunction) => {

// DNS-rebinding defense: when bound to loopback, only answer requests addressed to a loopback host name.
export function hostHeaderAllowed(hostHeader: string | undefined, bindHost = HOST): boolean {
if (!LOOPBACK_BIND_HOSTS.has(bindHost)) return true; // operator or container ingress explicitly exposed it
if (!hostHeader) return false;
try {
const hostname = new URL(`http://${hostHeader}`).hostname.toLowerCase();
return hostname === 'localhost' || hostname === '127.0.0.1' || hostname === '[::1]' || hostname === '::1';
} catch {
return false;
}
function sameOriginOnly(req: Request, res: Response, next: NextFunction) {
if (req.headers['sec-fetch-site'] === 'cross-site') {
res.status(403).json({ error: 'Cross-site access to local AI proxy is forbidden.' });
return;
}
const origin = req.headers.origin;
if (!origin) {
next();
return;
}
const forwardedHost = req.headers['x-forwarded-host'];
const expectedHost = (
(Array.isArray(forwardedHost) ? forwardedHost[0] : forwardedHost) ||
req.headers.host ||
''
)
.split(',')[0]
.trim();
try {
const parsedOrigin = new URL(origin);
if (!expectedHost || parsedOrigin.host !== expectedHost) {
res.status(403).json({ error: 'Cross-origin access to local AI proxy is forbidden.' });
return;
}
next();
} catch {
res.status(403).json({ error: 'Invalid Origin header.' });
}

export function parseParamBillions(lower: string): { label: string; billions: number } | null {
const paramMatch = lower.match(/(?:^|[:\-_/\s])(e?\d+(?:\.\d+)?b)(?:$|[:\-_/\s])/);
if (!paramMatch) return null;

if (Number.isNaN(numeric)) return null;

}
// Tags without an explicit size resolve to these defaults in the Ollama library.
const LATEST_TAG_PARAMS: Record<string, number> = {
gemma4: 4,
gemma3n: 4,
gemma3: 4,
gemma2: 9,
codegemma: 7,
gemma: 7,
};
/** Embedding / safety-classifier / vision-only variants cannot chat and must never be auto-selected. */
const NON_CHAT_RE = /(embedding|shield|siglip|paligemma)/;
/**
* Capability multiplier per generation. A newer generation is worth ≈2.4x the parameters of
* Gemma 3 (Gemma 4 12B ≈ Gemma 3 27B class), so a large older model can still beat a tiny
* new one while, at equal size, the newest generation always wins. Future generations
* (gemma5, ...) scale upward automatically instead of falling into a generic bucket.
*/
export function generationFactor(family: GemmaModelInfo['family'], generation: number): number {
if (family === 'codegemma') return 0.6;
if (generation >= 4) return 2.4 + (generation - 4) * 0.8;
if (generation === 3) return 1.0;
if (generation === 2) return 0.7;
return 0.5;
}
// Rank free Google Gemma models: higher = more capable. Non-chat variants and non-Gemma models rank 0.
export function classifyAndRankModel(
name: string,
sizeBytes?: number,
quantization?: string
): GemmaModelInfo {
const lower = name.toLowerCase();
const base = lower.split('/').pop() || lower;
let family: GemmaModelInfo['family'] = 'other';
let generation = 0;
const gen = base.match(/gemma[-_ ]?(\d+)(n)?(?![a-z0-9])/);
if (base.includes('codegemma')) {
family = 'codegemma';
generation = 1;
} else if (gen) {
generation = parseInt(gen[1], 10);
family =
generation === 4
? 'gemma4'
: generation === 3
? gen[2]
? 'gemma3n'
: 'gemma3'
: generation === 2
? 'gemma2'
: 'gemma';
} else if (base.includes('gemma')) {
family = 'gemma';
generation = 1;
}
let parameterLabel = '';
let billions = 0;
const parsedParam = parseParamBillions(lower);
if (parsedParam) {
parameterLabel = parsedParam.label;
billions = parsedParam.billions;
} else if (family !== 'other') {
billions = LATEST_TAG_PARAMS[family] ?? 0;
// Bare "gemma4" tag in Ollama aliases to E4B
if (family === 'gemma4' && !lower.includes(':')) parameterLabel = 'E4B';
}
const chatCapable = !NON_CHAT_RE.test(base);
const rankScore =
family === 'other' || !chatCapable
? 0
: Math.max(0.1, billions) * generationFactor(family, generation);
return {
id: name,
name,
family,
parameterLabel,
sizeBytes,
quantization,
rankScore,
};
}
/** Best installed chat-capable Gemma; falls back to any other model, never an embedding/safety variant. */
export function pickRecommendedModel(models: GemmaModelInfo[]): GemmaModelInfo | null {
const sorted = [...models].sort((a, b) => b.rankScore - a.rankScore);
return (
sorted.find((m) => m.family !== 'other' && m.rankScore > 0) ||
sorted.find((m) => m.family === 'other') ||
null
);
}

Overall assessment
GemmaVault is a well-built local chat client plus encrypted snippet vault. Its runtime handling is strong: loopback-only proxy, DNS-rebinding guard, watchdog timeouts, reasoning-trace handling, and model ranking. It is not yet an AI coding tool in the sense of Cursor, Claude Code, Copilot, Continue, Aider or Cline. Those work on your real codebase. This one works on pasted or attached snippets. Most of the gaps below follow from that.
Tier 1: the biggest functional gaps
No real codebase access. There is no folder or repo picker, file tree, git awareness or file watching. Context is whatever you manually attach (snippets and docs). Industry tools support `@file`, `@folder` and `@symbol` mentions and automatically pull in relevant files.
No codebase indexing or retrieval. There is no repo map (tree-sitter), no embeddings and no hybrid search. `embeddinggemma` is explicitly excluded from model selection, so the app never uses it for retrieval either. Search in `SnippetsView` is plain substring matching.
No IDE integration or inline completion. There is no VS Code or JetBrains extension, no LSP use, and no tab-completion or fill-in-the-middle. `codegemma:7b` is listed as a recommended model, but nothing uses its FIM capability.
No edit/apply workflow. Output becomes whole-snippet “child versions”. There are no diffs, no apply-patch, no multi-file edits, and no accept/reject per hunk. Lineage links parent and child, but I found no diff view between versions.
No agentic loop. I found no tool calling (Ollama supports it), no terminal or sandbox, no run-tests-and-fix cycle, no plan mode, no checkpoints or undo, and no permission model. The “Unit Tests” and “Debug” actions generate code but never execute or verify it.
Tier 2: quality and technical depth
Context management is heuristic.
The budget uses a ~3.2 chars/token guess rather than a tokenizer or Ollama’s `prompt_eval_count`.
History is hard-capped to the last 16 turns.
Over-budget content is cut with `slice()`, which can cut mid-code-block.
There is no summarisation or compaction of older turns.
The default `num_ctx` of 8192 is small for code work.
Prompt structure hurts local-inference speed. Attached context is concatenated into the system message, so the prefix changes whenever attachments change. That defeats KV-cache reuse in Ollama and llama.cpp. Keeping a stable prefix and appending context after it would cut latency noticeably on CPU. `keep_alive` is also not exposed, so models may unload between uses.
Gemma-only lock-in. Setup rejects non-Gemma tags, and the ranking table is hand-coded. Strong local coding models (Qwen-Coder, DeepSeek-Coder, Devstral and similar) are second-class. There is also no per-task routing, such as a small model for completion and a large one for chat.
Thin generation controls. Only temperature, max tokens and context are exposed. There is no `top_p`, `top_k`, seed, repeat penalty or stop sequences, and no structured or grammar-constrained output. Code extraction depends on the model fencing blocks correctly. Tokens/sec and prompt-eval stats are not surfaced.
Generated code is not validated. Before saving a child snippet, nothing parses it, so syntax errors get filed as a new “version”. Highlighting is a custom regex tokenizer (`syntax.ts`) rather than tree-sitter or Shiki. The editor is a plain `<textarea>`, with no Monaco or CodeMirror, so no bracket matching, folding, multi-cursor or find/replace.
Fixed per-action prompts. Explain, Debug, Refactor and the rest are built in. Users can’t define custom commands, slash commands or project rules files (like `AGENTS.md` or `.cursorrules`).
Tier 3: engineering and security hardening
Quality infrastructure is light. Tests cover the logic layers (db, crypto, server, lineage) but not the UI. There is no end-to-end suite (Playwright), no CI config, and no ESLint or Prettier (`lint` is just `tsc --noEmit`). There is also no eval harness to check whether prompt or model changes improve output.
Security defaults.
Encryption is off until the user sets a passphrase.
The proxy accepts any loopback port, which lets a browser page talk to arbitrary local services over those probe and chat paths. An allowlist of runtime ports would be tighter.
Once tools or file access are added, prompt injection from attached docs becomes a real risk and needs guarding.
PBKDF2 at 600k iterations is acceptable, but a WASM Argon2id option would be stronger.
Storage and portability. Data lives only in IndexedDB, and backups use a proprietary `.gvbackup` format. There is no import from or export to a real folder or git repo, no Markdown/file export, and no sync. A full-vault decrypt-then-substring search won’t scale to large vaults, so it needs a real full-text index.
Large components. `App.tsx` (about 1,100 lines), `db.ts` (about 1,200) and several 30 KB+ view components would benefit from splitting before more features are added.

Workspace folder mounting via the File System Access API or a server-side path allowlist, with `@file` mentions.

Tree-sitter parsing for repo maps, syntax validation and highlighting.
A local embedding index (`embeddinggemma` or similar) for retrieval.
Tool calling with a sandboxed run-tests-and-fix loop and explicit permission prompts.

I picked these three by value against effort and by dependency order. The prompt/budget work comes first because the other two need it, and the edit workflow needs the workspace access from the second.
Recommended build order: 1) context and prompt engine → 2) workspace and retrieval → 3) edit/diff workflow. The effort estimates are rough: about 1 week, 2–3 weeks and 2 weeks.
Design 1: Cache-friendly prompts, real token budgeting, compaction
Problems in the current code
`buildGemmaMessages` puts attachments in the system message. Any attachment change alters the start of the prompt, so Ollama and llama.cpp must re-process the whole prompt.
The budget is `chars × 3.2`, history is cut with `slice(-16)`, and overflow is cut with `slice()`, possibly mid-code-fence.
Design
Append-only transcript layout.
```
[system: static prompt + project rules]      ← never changes
[turn 1 user: contextPack₁ + question₁]
[turn 1 assistant]
[turn 2 user: contextPack₂ + question₂]      ← only this is new
```
Volatile context goes in the latest user message, never the system message. Each message persists the exact text that was sent (add `sentContext?: string` or a content hash to `ChatMessage`). On later turns the same text is replayed byte-for-byte, so the model reuses its cached prefix. Only the new turn is processed.
Prefix-stability rules. Never re-render older turns, never reorder attachments, and never change `num_ctx` mid-session (it forces a model reload). Prior `thinking` is already excluded from requests, which is correct.
Measured token counts instead of guessed ones.
Ollama’s final stream chunk includes `prompt_eval_count`, `eval_count`, `eval_duration` and `load_duration`. OpenAI-compatible servers report `usage` or `timings`.
Keep a per-model running ratio of chars per token, split by code and prose, and apply a ~10% safety margin. This needs no tokenizer dependency and improves with use.
Show a context meter and tokens/sec in the UI.
Budget allocator. `input = num_ctx − reserve(max_tokens + thinking headroom)`. Allocate roughly: fixed system 5–10%, history up to 35%, context pack up to 50%, and the user’s message guaranteed. The truncation unit becomes a whole chunk, dropping the lowest-ranked first. It never cuts inside a code fence.
Compaction instead of dropping.
Trigger when history exceeds about 60% of its budget.
Summarise the oldest turns with the same model (`think:false` for speed) into a structured note: goal, decisions, files touched, open issues, key code facts.
Store it as `session.summary` with the covered message range, keep the last 4 turns verbatim, and let the user view and edit the summary.
This changes the prefix once (one cache miss), after which it is stable again.
Expose `keep_alive` (for example 30 minutes) so the model isn’t unloaded between questions.
Acceptance tests
A deterministic unit test: the messages built for turn N must be an exact prefix of those for turn N+1.
Benchmark follow-up time-to-first-token, cold vs warm, on `e4b`. The target is warm prompt-eval under about 20% of cold.
Truncation tests that never produce an unclosed fence.
Design 2: Workspace access, indexing and retrieval
Architecture. Use the existing Node server. A browser PWA can’t read arbitrary paths, and the app already trusts loopback-only. Add an optional File System Access API fallback (Chromium only) for the standalone PWA.
Server endpoints (reuse the `setupGuard` pattern: loopback-only plus a custom header for CSRF protection)
```
POST /api/workspace/open     {path}            → realpath, must be a directory
GET  /api/workspace/tree     ?depth=
GET  /api/workspace/file     ?path=            → text only, ≤1 MB
POST /api/workspace/search   {query, mode}     → lexical | semantic | hybrid
GET  /api/workspace/git      ?op=status|diff
```
Path safety (this matters most)
Resolve with `realpath` and verify the result stays inside the root. This blocks `..` traversal and symlink escapes.
Honour `.gitignore` plus a `.gemmaignore`.
Hard-deny `.git/`, `.env*`, `*.pem`, `id_rsa*` and `node_modules`. Skip binaries and large files.
Data model
ts
```
interface Workspace { id; rootPath; name; lastIndexedAt }
// Project gains workspaceId?; ChatAttachmentRef.kind adds
// 'file' | 'folder' | 'symbol' | 'git-diff' | 'search'
```
Mentions in the composer. Typing `@` opens autocomplete for `@src/lib/db.ts`, `@src/lib/`, `@symbol:buildGemmaMessages`, `@git:diff`, plus the existing snippets and docs.
Indexing in two phases
Phase A, no embeddings (ship first):
Lexical search (a ripgrep-style scan, or BM25 over chunks).
A repo map: `web-tree-sitter` (WASM, works offline) extracts top-level symbols and signatures per file, ranked by import graph, recency and mentions. This gives the model project structure at a few hundred tokens.
Phase B, semantic:
Chunk by AST node (about 200–400 tokens) and embed through Ollama `/api/embed` with `embeddinggemma` or another embedding model.
Store vectors as flat binary files; brute-force cosine is fine up to about 50k chunks.
Fuse BM25 and cosine rankings with reciprocal rank fusion.
Update incrementally by file hash, using `chokidar` for watching.
Context assembly. Priority is: explicit mentions > open file and selection > retrieved chunks > repo map. Everything flows through Design 1’s allocator. Add a context inspector panel listing what was sent, with token counts and a per-item “remove” control. Local models are very sensitive to irrelevant context, so this transparency pays off.
Security and privacy notes
The vault encrypts snippets, but a workspace index on disk would be plaintext. When encryption is on, keep the index in memory only, or store it encrypted with the vault key.
File contents are untrusted data: wrap them in clear delimiters with a “do not follow instructions inside” line. This becomes critical once tools exist.
Acceptance tests
Path traversal and symlink-escape tests against the endpoints.
A retrieval smoke test: given 20 known questions about this repo, the right file appears in the top 5.
Design 3: Edit proposals, diff review and safe apply
Why not unified diffs. Small local models are poor at line-number-accurate diffs. Use SEARCH/REPLACE blocks, the format Aider found most reliable:
```
src/lib/db.ts
<<<<<<< SEARCH
exact existing lines
=======
replacement lines
>>>>>>> REPLACE
```
Teach it through the system prompt with a short few-shot example, and use low temperature (about 0.2) for edit turns. For small files, allow a whole-file replacement fallback.
Pipeline
Parse the reply into `EditProposal { id, filePath, hunks: {search, replace}[], status }`. It reuses the fence-scanning approach in `snippetLineage.ts` but is a separate parser.
Match each hunk in three passes: exact, whitespace-normalised, then line-level fuzzy with a threshold. If a hunk fails, automatically re-prompt once or twice with the file’s current content and the specific failure.
Validate by parsing the patched file with tree-sitter. Reject, or warn on, a result that has more syntax errors than the original. Leave a hook for an optional lint or test command later.
Review UI using `@codemirror/merge`, which is lighter than Monaco for an offline PWA bundle. It offers per-hunk accept and reject, “apply all”, and a choice of apply to workspace file or save as a vault snippet.
Apply through `POST /api/workspace/apply {path, expectedHash, newContent}`:
Reject if the file hash changed on disk since proposal (no silent overwrite).
Write atomically (temp file plus rename), and only inside the workspace root.
Save the pre-image to `.gemmavault/checkpoints/<ts>/` for one-click Undo.
If the repo is git, show `git diff` afterwards and never auto-commit.
Lineage integration. Add `patch?` and `baseHash?` to `CodeSnippet`. New children store a patch against the parent instead of a full copy, and existing full-code children keep working unchanged. This also gives you the missing diff view between versions for free.
Acceptance tests
Fuzz the parser with malformed blocks, including unclosed and nested fences.
Test the fuzzy applier on indentation drift and CRLF files.
A small golden set of recorded model outputs to catch regressions in prompt wording.
Follow-on (not in this top 3)
Once these exist, tool calling and a sandboxed run-tests-and-fix loop becomes a natural next step. It reuses the workspace endpoints, the apply and checkpoint safety, and the allocator, so it is far cheaper to add afterwards than before.

/**
 * Small .gitignore matcher (no dependencies). Supports comments, negation (!), directory-only
 * patterns (trailing /), anchored patterns (leading / or an inner /), *, ?, ** and character classes.
 * Good enough to keep build output and vendored code out of an index; it is not a Git replacement.
 */

interface Rule {
  re: RegExp;
  negate: boolean;
  dirOnly: boolean;
}

function globToRegex(glob: string, anchored: boolean): RegExp {
  let out = '';
  for (let i = 0; i < glob.length; i++) {
    const c = glob[i];
    if (c === '*') {
      if (glob[i + 1] === '*') {
        // "**/" matches zero or more directories; a trailing "**" matches everything below.
        if (glob[i + 2] === '/') {
          out += '(?:.*/)?';
          i += 2;
        } else {
          out += '.*';
          i += 1;
        }
      } else {
        out += '[^/]*';
      }
    } else if (c === '?') {
      out += '[^/]';
    } else if (c === '[') {
      const end = glob.indexOf(']', i + 1);
      if (end > i + 1) {
        out += `[${glob.slice(i + 1, end).replace(/^!/, '^').replace(/\\/g, '\\\\')}]`;
        i = end;
      } else {
        out += '\\[';
      }
    } else if (c === '\\' && i + 1 < glob.length) {
      out += glob[i + 1].replace(/[.*+?^${}()|[\]\\/]/g, '\\$&');
      i += 1;
    } else {
      out += c.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
    }
  }
  return new RegExp(`^${anchored ? '' : '(?:.*/)?'}${out}$`);
}

export class IgnoreMatcher {
  private rules: Rule[] = [];

  add(text: string): this {
    for (const raw of text.split(/\r?\n/)) {
      let line = raw.replace(/\s+$/, '');
      if (!line || line.startsWith('#')) continue;
      let negate = false;
      if (line.startsWith('!')) {
        negate = true;
        line = line.slice(1);
      }
      let dirOnly = false;
      if (line.endsWith('/')) {
        dirOnly = true;
        line = line.slice(0, -1);
      }
      if (!line) continue;
      const anchored = line.startsWith('/') || line.includes('/');
      if (line.startsWith('/')) line = line.slice(1);
      this.rules.push({ re: globToRegex(line, anchored), negate, dirOnly });
    }
    return this;
  }

  /** `rel` is a forward-slash path relative to the directory the .gitignore lives in. */
  ignores(rel: string, isDir: boolean): boolean {
    let ignored = false;
    // A parent directory that is ignored hides everything below it.
    const parts = rel.split('/');
    for (let i = 1; i < parts.length; i++) {
      if (this.test(parts.slice(0, i).join('/'), true)) return true;
    }
    if (this.test(rel, isDir)) ignored = true;
    return ignored;
  }

  private test(rel: string, isDir: boolean): boolean {
    let ignored = false;
    for (const r of this.rules) {
      if (r.dirOnly && !isDir) continue;
      if (r.re.test(rel)) ignored = !r.negate;
    }
    return ignored;
  }

  if (!patterns) return [];

  for (let i = 0; i < lines.length && out.length < 400; i++) {
    const line = lines[i];
    if (language === 'markdown' && /^\s*(```|~~~)/.test(line)) inFence = !inFence;
    if (inFence || line.length > 400) continue;

        path: relPath,
        line: i + 1,
        signature: line.trim().replace(/\s*\{\s*$/, '').slice(0, 140),
      });
      break;

}

export interface Bm25Index {
  df: Map<string, number>;
  avgLen: number;
  n: number;
}

export function buildBm25(chunks: Chunk[]): Bm25Index {
  const df = new Map<string, number>();
  let total = 0;
  for (const c of chunks) {
    total += c.len;
    for (const t of c.tf.keys()) df.set(t, (df.get(t) ?? 0) + 1);
  }
  return { df, avgLen: chunks.length ? total / chunks.length : 1, n: chunks.length };
}

const STOP = new Set(['the', 'and', 'for', 'how', 'what', 'why', 'does', 'this', 'that', 'with', 'from', 'are', 'is', 'in', 'of', 'to', 'a', 'it', 'on', 'do', 'be', 'can', 'my', 'me', 'we', 'you', 'about', 'please', 'explain', 'show', 'tell']);

export function queryTerms(query: string): string[] {
  const seen = new Set<string>();
  for (const t of tokenize(query)) if (!STOP.has(t)) seen.add(t);
  return [...seen];
}

export function bm25Search(chunks: Chunk[], idx: Bm25Index, query: string, limit: number): Array<{ chunk: Chunk; score: number }> {
  const terms = queryTerms(query);
  if (terms.length === 0 || idx.n === 0) return [];
  const k1 = 1.4;
  const b = 0.75;
  const scored: Array<{ chunk: Chunk; score: number }> = [];
  for (const chunk of chunks) {
    let score = 0;
    for (const t of terms) {
      const f = chunk.tf.get(t);
      if (!f) continue;
      const n = idx.df.get(t) ?? 0;
      const idf = Math.log(1 + (idx.n - n + 0.5) / (n + 0.5));
      score += (idf * (f * (k1 + 1))) / (f + k1 * (1 - b + (b * chunk.len) / idx.avgLen));
    }
    if (score > 0) scored.push({ chunk, score });
  }
  scored.sort((a, b2) => b2.score - a.score);
  return scored.slice(0, limit);
}

/** Reciprocal rank fusion of several ranked lists of chunk ids. */
export function fuseRanks(lists: number[][], k = 60): Map<number, number> {
  const out = new Map<number, number>();
  for (const list of lists) list.forEach((id, rank) => out.set(id, (out.get(id) ?? 0) + 1 / (k + rank + 1)));
  return out;
}

function importTarget(from: string, spec: string, files: Map<string, FileEntry>): string | null {
  if (!spec.startsWith('.')) return null;
  const base = path.posix.normalize(path.posix.join(path.posix.dirname(from), spec));
  const candidates = [base, `${base}.ts`, `${base}.tsx`, `${base}.js`, `${base}.jsx`, `${base}.mjs`, `${base}.py`, `${base}/index.ts`, `${base}/index.tsx`, `${base}/index.js`, `${base}/__init__.py`];
  for (const c of candidates) if (files.has(c)) return c;
  // TypeScript sources imported as "./x.ts" or "./x.js"
  const stripped = base.replace(/\.(js|mjs)$/, '');
  for (const ext of ['.ts', '.tsx']) if (files.has(stripped + ext)) return stripped + ext;
  return null;
}

export function rankFiles(files: Map<string, FileEntry>, focus: string[] = []): FileEntry[] {
  const inbound = new Map<string, number>();
  for (const f of files.values()) {
    for (const spec of f.imports) {
      const target = importTarget(f.path, spec, files);
      if (target && target !== f.path) inbound.set(target, (inbound.get(target) ?? 0) + 1);
    }
  }
  const newest = Math.max(1, ...[...files.values()].map((f) => f.mtimeMs));
  const oldest = Math.min(newest, ...[...files.values()].map((f) => f.mtimeMs));
  const span = Math.max(1, newest - oldest);
  const focusSet = new Set(focus);
  const score = (f: FileEntry) => {
    let s = Math.log2(1 + (inbound.get(f.path) ?? 0)) * 2;
    s += ((f.mtimeMs - oldest) / span) * 1.5;
    if (focusSet.has(f.path)) s += 10;
    else if (focus.some((p) => path.posix.dirname(p) === path.posix.dirname(f.path))) s += 1.5;
    if (/(^|\/)(index|main|app|server)\.[a-z]+$/.test(f.path)) s += 1;
    if (/(^|\/)(tests?|__tests__|spec)\//.test(f.path) || /\.(test|spec)\./.test(f.path)) s -= 1.5;
    return s;
  };
  return [...files.values()].filter((f) => f.indexed && f.symbols.length > 0).sort((a, b) => score(b) - score(a) || a.path.localeCompare(b.path));
}

  return { text: out.join('\n'), files: nFiles, symbols: nSyms };
}

/** Subsequence-aware path scoring for @-mention autocomplete. Higher is better; 0 = no match. */
export function scorePath(rel: string, query: string): number {
  const q = query.toLowerCase();
  const p = rel.toLowerCase();
  if (!q) return 1;
  const base = p.slice(p.lastIndexOf('/') + 1);
  if (base === q) return 100;
  if (base.startsWith(q)) return 80 - Math.min(20, base.length - q.length);
  if (base.includes(q)) return 60 - Math.min(20, base.length - q.length);
  if (p.includes(q)) return 40 - Math.min(20, p.length / 10);
  // fuzzy subsequence on the whole path
  let qi = 0;
  let gaps = 0;
  let last = -1;
  for (let i = 0; i < p.length && qi < q.length; i++) {
    if (p[i] === q[qi]) {
      if (last >= 0 && i - last > 1) gaps++;
      last = i;
      qi++;
    }
  }
  return qi === q.length ? Math.max(1, 25 - gaps * 3) : 0;
}

  const fresh = (st: WorkspaceState): WorkspaceState => {
    if (Date.now() - st.scannedAt < REFRESH_AFTER_MS) return st;
    const next = buildState(st.root, st);
    states.set(st.root, next);
    if (next.embed.setting) void runEmbedding(next);
    return next;
  };

  // ---- embeddings -------------------------------------------------------------------------------

  async function embedTexts(setting: EmbeddingSetting, input: string[]): Promise<Float32Array[]> {
    const ctl = new AbortController();
    const timer = setTimeout(() => ctl.abort(), 60_000);
    try {
      const res = await doFetch(new URL('/api/embed', setting.baseUrl).toString(), {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ model: setting.model, input }),
        signal: ctl.signal,
        redirect: 'error',
      });
      if (!res.ok) throw new Error(`Embedding model returned HTTP ${res.status}. Is "${setting.model}" installed (ollama pull ${setting.model})?`);
      const json = (await res.json()) as { embeddings?: number[][] };
      if (!Array.isArray(json.embeddings) || json.embeddings.length !== input.length) throw new Error('Embedding model returned an unexpected response.');
      return json.embeddings.map(normalize);
    } finally {
      clearTimeout(timer);
    }
  }

  async function runEmbedding(st: WorkspaceState): Promise<void> {
    const setting = st.embed.setting;
    if (!setting || st.embed.state === 'running') return;
    const token = ++st.embed.token;
    st.embed.state = 'running';
    st.embed.error = undefined;
    try {
      const wanted = new Map<string, Chunk>();
      for (const c of st.scan.chunks.slice(0, MAX_EMBED_CHUNKS)) wanted.set(vecKey(c), c);
      for (const k of st.vectors.keys()) if (!wanted.has(k)) st.vectors.delete(k);
      const todo = [...wanted.entries()].filter(([k]) => !st.vectors.has(k));
      for (let i = 0; i < todo.length; i += EMBED_BATCH) {
        if (st.embed.token !== token || st.embed.setting !== setting) return; // superseded or closed
        const batch = todo.slice(i, i + EMBED_BATCH);
        const vecs = await embedTexts(setting, batch.map(([, c]) => `${c.path}\n${c.text}`.slice(0, 1800)));
        batch.forEach(([k], j) => st.vectors.set(k, vecs[j]));
      }
      st.embed.state = 'idle';
    } catch (e) {
      st.embed.state = 'error';
      st.embed.error = e instanceof Error ? e.message : 'Embedding failed.';
    }
  }

  // ---- public operations -------------------------------------------------------------------------

  const info = (st: WorkspaceState): WorkspaceInfo => ({
    rootPath: st.root,
    name: st.name,
    fileCount: st.scan.files.size,
    chunkCount: st.scan.chunks.length,
    totalBytes: st.scan.totalBytes,
    truncated: st.scan.truncated,
    isGit: fs.existsSync(path.join(st.root, '.git')),
    indexedAt: st.scannedAt,
    embeddings: {
      model: st.embed.setting?.model ?? '',
      embedded: st.vectors.size,
      total: Math.min(st.scan.chunks.length, MAX_EMBED_CHUNKS),
      state: st.embed.setting ? st.embed.state : 'off',
      error: st.embed.error,
    },
  });

  function setEmbedding(st: WorkspaceState, setting: EmbeddingSetting | null | undefined) {
    const next = setting && setting.model.trim() && isLoopbackHttpUrl(setting.baseUrl) ? { baseUrl: setting.baseUrl.replace(/\/+$/, ''), model: setting.model.trim() } : null;
    const cur = st.embed.setting;
    if (cur?.model === next?.model && cur?.baseUrl === next?.baseUrl) return;
    st.vectors.clear();
    st.embed = { setting: next, state: next ? 'idle' : 'off', token: st.embed.token + 1 };
    if (next) void runEmbedding(st);
  }

  return {
    async open(rawPath: string, embedding?: EmbeddingSetting | null): Promise<WorkspaceInfo> {
      const root = resolveRoot(rawPath);
      let st = states.get(root);
      st = buildState(root, st);
      states.set(root, st);
      setEmbedding(st, embedding);
      return info(st);
    },

    close(rawPath: string): void {
      states.delete(resolveRoot(rawPath));
    },

    info(rawRoot: string, embedding?: EmbeddingSetting | null): WorkspaceInfo {
      const st = fresh(get(rawRoot));
      setEmbedding(st, embedding);
      return info(st);
    },

    files(rawRoot: string, query: string, limit = 8): FileListResult {
      const st = fresh(get(rawRoot));
      const q = String(query ?? '').trim();
      const lim = Math.max(1, Math.min(30, limit));
      const files = [...st.scan.files.values()]
        .map((f) => ({ f, s: scorePath(f.path, q) }))
        .filter((x) => x.s > 0)
        .sort((a, b) => b.s - a.s || b.f.mtimeMs - a.f.mtimeMs)
        .slice(0, lim)
        .map(({ f }) => ({ path: f.path, size: f.size, language: f.language }));
      const dirs = q
        ? [...st.scan.dirs].map((d) => ({ d, s: scorePath(d, q) })).filter((x) => x.s > 0).sort((a, b) => b.s - a.s || a.d.localeCompare(b.d)).slice(0, 4).map((x) => x.d)
        : [];
      return { files, dirs };
    },

    tree(rawRoot: string, dir = '', depth = 2): TreeEntry[] {
      const st = fresh(get(rawRoot));
      const base = dir.replace(/\\/g, '/').replace(/^\/+|\/+$/g, '');
      if (base) resolveInside(st.root, base);
      const maxDepth = Math.max(1, Math.min(6, depth));
      const prefix = base ? `${base}/` : '';
      const out: TreeEntry[] = [];
      for (const d of [...st.scan.dirs].sort()) {
        if (d.startsWith(prefix) && d.slice(prefix.length).split('/').length <= maxDepth) out.push({ path: d, type: 'dir' });
      }
      for (const f of st.scan.files.values()) {
        if (f.path.startsWith(prefix) && f.path.slice(prefix.length).split('/').length <= maxDepth) out.push({ path: f.path, type: 'file', size: f.size });
      }
      return out.sort((a, b) => a.path.localeCompare(b.path)).slice(0, 500);
    },

    /** Reads one file (text only, redacted). `startLine`/`endLine` are 1-based and inclusive. */
    read(rawRoot: string, rel: string, startLine?: number, endLine?: number): FileRead {
      const st = get(rawRoot);
      const abs = resolveInside(st.root, rel);
      const stat = fs.statSync(abs);
      if (!stat.isFile()) throw new WorkspaceError('That path is a folder; mention it as a folder instead.');
      if (stat.size > LIMITS.maxReadBytes) throw new WorkspaceError(`File is larger than ${Math.round(LIMITS.maxReadBytes / 1000)} KB; mention a line range or search instead.`, 413);
      const buf = fs.readFileSync(abs);
      if (looksBinary(buf)) throw new WorkspaceError('Binary files cannot be attached.', 415);
      const redacted = redactSecrets(buf.toString('utf8').replace(/\r\n?/g, '\n'));
      const lines = redacted.text.split('\n');
      const from = Math.max(1, Math.floor(startLine ?? 1));
      const to = Math.min(lines.length, Math.floor(endLine ?? lines.length));
      if (from > lines.length) throw new WorkspaceError('Line range is past the end of the file.');
      const relReal = path.relative(st.root, abs).split(path.sep).join('/');
      return {
        path: relReal,
        language: languageOf(relReal),
        content: lines.slice(from - 1, Math.max(from, to)).join('\n'),
        startLine: from,
        endLine: Math.max(from, to),
        totalLines: lines.length,
        truncated: from > 1 || to < lines.length,
        redactions: redacted.count,
      };
    },

    symbols(rawRoot: string, query: string, limit = 6): SymbolHit[] {
      const st = fresh(get(rawRoot));
      const q = String(query ?? '').trim().toLowerCase();
      if (!q) return [];
      const scored: Array<{ s: SymbolHit; score: number }> = [];
      for (const f of st.scan.files.values()) {
        for (const s of f.symbols) {
          const n = s.name.toLowerCase();
          let score = 0;
          if (n === q) score = 100;
          else if (n.startsWith(q)) score = 70;
          else if (n.includes(q)) score = 45;
          else continue;
          if (s.kind === 'module' && f.language === 'markdown') score -= 30;
          scored.push({ s, score: score - Math.min(10, n.length - q.length) / 2 });
        }
      }
      return scored.sort((a, b) => b.score - a.score || a.s.path.localeCompare(b.s.path)).slice(0, Math.max(1, Math.min(20, limit))).map((x) => x.s);
    },

    async search(rawRoot: string, query: string, mode: SearchMode = 'hybrid', limit = 6, embedding?: EmbeddingSetting | null): Promise<SearchResult> {
      let st = fresh(get(rawRoot));
      setEmbedding(st, embedding);
      st = states.get(st.root)!;
      const lim = Math.max(1, Math.min(20, limit));
      const q = String(query ?? '').trim().slice(0, 2000);
      if (!q) return { hits: [], mode: 'lexical' };

      const lexical = mode === 'semantic' ? [] : bm25Search(st.scan.chunks, st.bm25, q, lim * 4);
      let semantic: Array<{ chunk: Chunk; score: number }> = [];
      if (mode !== 'lexical' && st.embed.setting && st.vectors.size > 0) {
        try {
          const [qv] = await embedTexts(st.embed.setting, [q.slice(0, 1800)]);
          for (const c of st.scan.chunks) {
            const v = st.vectors.get(vecKey(c));
            if (v) semantic.push({ chunk: c, score: dot(qv, v) });
          }
          semantic.sort((a, b) => b.score - a.score);
          semantic = semantic.slice(0, lim * 4).filter((x) => x.score > 0.2);
        } catch {
          semantic = [];
        }
      }

      const usedSemantic = semantic.length > 0;
      const rankedIds = (usedSemantic && lexical.length > 0)
        ? fuseRanks([lexical.map((x) => x.chunk.id), semantic.map((x) => x.chunk.id)])
        : new Map((usedSemantic ? semantic : lexical).map((x, i) => [x.chunk.id, 1 / (60 + i + 1)]));
      const inLex = new Set(lexical.map((x) => x.chunk.id));
      const inSem = new Set(semantic.map((x) => x.chunk.id));
      const best = [...rankedIds.entries()].sort((a, b) => b[1] - a[1]);

      // One hit per file keeps the context diverse; neighbouring chunks of a file are rarely both needed.
      const perFile = new Map<string, number>();
      const hits: SearchHit[] = [];
      for (const [id, score] of best) {
        const c = st.scan.chunks[id];
        const n = perFile.get(c.path) ?? 0;
        if (n >= 1) continue;
        perFile.set(c.path, n + 1);
        hits.push({
          path: c.path, startLine: c.startLine, endLine: c.endLine, text: c.text,
          score: Number(score.toFixed(5)),
          via: inLex.has(id) && inSem.has(id) ? 'both' : inSem.has(id) ? 'semantic' : 'lexical',
        });
        if (hits.length >= lim) break;
      }
      return { hits, mode: usedSemantic ? (lexical.length > 0 ? 'hybrid' : 'semantic') : 'lexical' };
    },

    repoMap(rawRoot: string, maxTokens = 800, focus: string[] = []): RepoMapResult {
      const st = fresh(get(rawRoot));
      const safeFocus = focus.filter((p) => typeof p === 'string' && !isDeniedPath(p)).slice(0, 20);
      return renderRepoMap(st.scan.files, Math.max(100, Math.min(4000, maxTokens)), safeFocus);
    },

    async git(rawRoot: string, op: GitOp): Promise<GitResult> {
      const st = get(rawRoot);
      if (!fs.existsSync(path.join(st.root, '.git'))) throw new WorkspaceError('This folder is not a Git repository.', 404);
      if (op !== 'status' && op !== 'diff') throw new WorkspaceError('Unsupported git operation.');
      const base = ['-c', 'core.fsmonitor=false', '-c', 'core.pager=cat', '--no-pager', '-c', 'diff.external='];
      const exclude = ['.env*', '*.pem', '*.key', 'id_rsa*', '*.p12', '*.pfx', '.npmrc', '.netrc', '*.sqlite', '*.sqlite3', '*.db', '*.gvbackup', '*.lock', 'package-lock.json']
        .map((g) => `:(exclude,glob)**/${g}`);
      const run = (args: string[]) =>
        new Promise<string>((resolve, reject) => {
          execFile('git', [...base, ...args], {
            cwd: st.root, timeout: gitTimeout, maxBuffer: 4_000_000,
            env: { ...process.env, GIT_OPTIONAL_LOCKS: '0', GIT_TERMINAL_PROMPT: '0' },
          }, (err, stdout) => (err ? reject(err) : resolve(stdout)));
        });
      let text: string;
      try {
        if (op === 'status') {
          text = await run(['status', '--short', '--branch', '--untracked-files=normal']);
        } else {
          const args = ['diff', '--no-ext-diff', '--no-textconv', '--no-color', '--unified=3'];
          try {
            text = await run([...args, 'HEAD', '--', '.', ...exclude]);
          } catch {
            // no commits yet: show staged + unstaged separately
            text = (await run([...args, '--cached', '--', '.', ...exclude])) + (await run([...args, '--', '.', ...exclude]));
          }
        }
      } catch (e) {
        const code = (e as { code?: string }).code;
        if (code === 'ENOENT') throw new WorkspaceError('Git is not installed or not on PATH.', 501);
        throw new WorkspaceError('Git could not read this repository.', 502);
      }
      const redacted = redactSecrets(text).text;
      const cap = 120_000;
      return { op, text: redacted.length > cap ? `${redacted.slice(0, cap)}\n…[diff truncated]` : redacted, truncated: redacted.length > cap };
    },
  };
}

function parseEmbedding(v: unknown): EmbeddingSetting | null {
  if (!v || typeof v !== 'object') return null;
  const { baseUrl, model } = v as { baseUrl?: unknown; model?: unknown };
  if (typeof baseUrl !== 'string' || typeof model !== 'string' || !model.trim()) return null;

export type WorkspaceOp = (typeof WORKSPACE_OPS)[number];

/** Transport-independent request handler. server.ts wires it to Express; tests call it directly. */
export async function handleWorkspaceOp(manager: WorkspaceManager, op: string, body: Record<string, unknown>): Promise<unknown> {
  const root = str(body.root);
  switch (op as WorkspaceOp) {
    case 'open':
      return manager.open(root, parseEmbedding(body.embedding));
